Privacy Policy

Last updated: October 5, 2026

This Privacy Policy describes how KWONIL ONE V2 handles information when a user connects Google services or uses connected features.

1. About KWONIL ONE V2

KWONIL ONE V2 is a personal-use AI workspace operated by its user. It provides a conversational interface for working with information and connected digital services.

2. Google services

KWONIL ONE V2 may connect to Google services only after the user explicitly authorizes access through Google OAuth.

Depending on the permissions granted by the user, features may include:

  • Reading and working with Gmail messages
  • Accessing files and documents in Google Drive
  • Viewing or managing Google Calendar information

3. Information accessed

KWONIL ONE V2 accesses only information required to provide the feature requested by the authorized user and only within the scope of permissions granted through Google OAuth.

This may include, when authorized and requested:

  • Gmail message metadata and message content
  • Google Drive file metadata and file content
  • Google Calendar event information
  • Basic Google account information required for authentication

4. How information is used

Google user data is used only to provide user-requested features, such as retrieving messages, finding files, reviewing calendar information, summarizing content, or preparing actions requested by the user.

If the user explicitly requests AI-assisted analysis of connected content, the minimum information necessary for that requested operation may be processed by the configured AI service provider.

5. Storage and OAuth credentials

OAuth credentials and authorization tokens may be stored by the local KWONIL ONE V2 system in order to maintain an authorized connection without requiring the user to sign in for every request.

Credentials are not intentionally displayed in public pages or exposed as part of normal application responses.

6. Sharing and sale of information

KWONIL ONE V2 does not sell Google user data and does not use Google user data for advertising.

Information is not shared with unrelated third parties except when necessary to provide a feature explicitly requested by the user or when required by law.

7. AI and model use

KWONIL ONE V2 does not independently use Google user data to train a general-purpose AI model.

When an authorized user requests AI processing, only information relevant to that requested task should be sent to the configured AI provider, subject to that provider's applicable API and privacy terms.

8. User control

The user controls which Google account is connected and which permissions are granted.

The user may revoke KWONIL ONE V2 access through Google account security settings or disconnect the account from KWONIL ONE V2.

9. Data retention and deletion

Connected data is retained only as needed for the user's requested functions, local records, or authorized workflows.

The user may disconnect Google access and may request deletion of locally retained connected-account data where applicable.

10. Security

KWONIL ONE V2 is designed to minimize unnecessary disclosure of credentials and connected data. Access to connected services is limited to authorized accounts and requested functions.

11. Google API Services User Data Policy

KWONIL ONE V2's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

12. Changes to this policy

This Privacy Policy may be updated when connected features or data handling practices change. The latest version will be published on this page.
